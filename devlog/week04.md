## 1️⃣ Gemini에게 보낸 게임 만들기 프롬프트

> **🎮 Gemini로 내 게임 만들기 → 3단계**에서 프롬프트를 복사하면 여기에 자동으로 들어가요.

```text
너는 고등학생과 함께 HTML 웹게임을 만드는 게임 개발자야.
맨 아래 [내 게임 기획서]는 내가 3주차에 정리한 게임 기획서야.
첨부한 이미지는 3주차에 만든 이 게임의 "스테이지 1" 화면 목업이야. 화면 배치, 색, 모양, 점수·버튼 위치는 이 목업을 최대한 따라 해.
이것을 바탕으로 "스테이지 1"을 실제로 플레이할 수 있는 웹게임으로 만들어 줘. Canvas에서 바로 실행해 볼 수 있게 만들어 줘.

[만드는 규칙]
- HTML 파일 하나에 HTML, CSS, JavaScript를 모두 넣어. 외부 이미지·소리 파일이나 라이브러리 없이 브라우저에서 바로 실행되게 해.
- 기획서의 5-1(시작할 때·플레이 중·클리어 조건·실패 조건), 5-2(등장하는 것들), 5-3(입력)을 하나도 빠뜨리지 말고 넣어.
- 화면 시점은 기획서의 화면 시점을 따라. 없으면 목업 이미지의 시점을 따라.
- 캐릭터와 물건은 도형, 이모지, Canvas 그리기로 단순하게 표현해.
- 기획서에 없는 기능(새 캐릭터, 스테이지 2, 상점, 업그레이드 등)은 넣지 마.
- 기획서에 숫자가 없는 것(속도, 시간, 개수 등)은 처음 하는 사람도 할 만한 값으로 정하고, 코드 맨 위에 "설정값"으로 모아 둬.
- 순서: 시작 화면(게임 제목, 조작법, 시작 버튼) → 게임 → 클리어 또는 게임오버 화면(결과, 다시 하기 버튼).
- 화면을 클릭하지 않아도 키보드가 바로 동작하게 하고, 방향키나 스페이스를 눌러도 페이지가 스크롤되지 않게 해.
- 코드 중요한 곳에 한국어 주석을 달아 줘.

[게임을 만든 다음 글로 알려 줘]
1. 기획서 반영 점검표: | 기획서 칸 | 게임에 넣은 방법 | ✅ 넣음 / 🔺 바꿈 / ❌ 못 넣음 |
2. 네가 정한 숫자: 기획서에 없어서 네가 정한 값(속도, 시간, 개수 등)과 코드 속 설정값 이름
3. 조작법
4. 처음 플레이할 때 꼭 확인해 볼 것 3가지

마지막에 "플레이해 보고 고치고 싶은 곳을 하나씩 말해 줘"라고 말해 줘.

[내 게임 기획서]
1. 한 문장 소개: 마법사인 플레이어가 단계를 넘어갈 때마다 능력을 얻을 수 있고 적이 강해지는 액션 게임
2. 타깃 플레이어: 액션 로그라이크를 좋아하는 사람들
3. 레퍼런스 게임:
   - Hades (장르: 액션 로그라이크) → 참고하고 싶은 점: 참고하고 싶은 점: 게임 시작전 고를 수 있는 다양한 무기와 게임 시작 후 얻을 수 있는 다양한 능력
   - Isaac (장르: 로그라이크, 액션, 어드벤쳐) → 참고하고 싶은 점: 많은 보스와 눈물로 공격을 한다는 독특한 아이디어
4. 핵심 재미 요소: 스테이지를 클리어 할수록 강해지는 플레이어와 몬스터들을 처리해 나가는 재미
5-1. 스테이지 1에서 일어나는 일:
   - 시작할 때: 캐릭터가 특정 마법 속성을 가지고 첫번째 스테이지에서 서있다
   - 플레이 중: 스테이지 클리어 시 다른 방으로 갈 수 있는 문이 여러개 있다. (방의 모든 몬스터 처치 시 보상과 함께 문이 자동으로 열림, 방 5개 클리어 후 6번째 방에 보스 방 문 등장)
   - 클리어 조건: 일반 방 5개 클리어 후 6번째 보스 방의 보스를 쓰러뜨리기
   - 실패 조건: 플레이어의 Hp가 전부 소진시 사망
5-2. 스테이지 1에 등장하는 것들:
   - 플레이어 → 갖고 있는 정보: Hp 100 / 하는 행동·규칙: 자유롭게 이동이 가능하며 공격을 할 수 있다. (기본 속성을 지니고 시작함)
   - 몬스터 → 갖고 있는 정보: 특정 속성에 내성과 약점이 있다 / 하는 행동·규칙: 플레이어를 발견시 플레이어를 쫓아온다
   - 문 → 갖고 있는 정보: 다음 방으로 넘어갈 수 있다 / 하는 행동·규칙: 넘어간 방에는 몬스터 또는 보상이 있다
   - 마법서 → 갖고 있는 정보: 다른 속성의 마법이나 특정 속성의 마법의 스킬을 배울 수 있다 / 하는 행동·규칙: 마법서가 나온 방은 몬스터가 나오지 않는다
5-3. 입력 방식: 키보드, 마우스
   - w,a,s,d → 이동
   - space → 대쉬
   - 마우스 좌클릭, 우클릭 → 마법 공격
5-4. 화면 시점: 탑다운 / 레퍼런스 게임(하데스, 아이작)의 장르적 특성과 360도 마우스 조작 및 적 위치 파악이 용이함
```
